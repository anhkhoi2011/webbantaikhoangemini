1. CẤU TRÚC THƯ MỤC SOURCE CODE:
--------------------------------------------------------------------------------
- index.html                   : Giao diện Landing Page bán hàng chuyên nghiệp cho khách hàng
                                 (Tích hợp đồng hồ đếm ngược, form đặt hàng, VietQR MBBank tự động,

                                 (Quản lý danh sách đơn hàng, cấp mã bản quyền tự động,

                                 (Định tuyến `/` cho khách và `/admin` cho trang quản trị, port 8080).
- START_SERVER.bat             : File chạy 1-click trên Windows (Nhấp đúp chuột là tự bật server

                                 + Cảnh báo khẩn cấp khi tồn kho <= ngưỡng cài đặt.
                                 + Báo cáo tổng kết ngày vào 10:00 sáng.
- GoogleAppsScript_CRM_AutoBot.js: Mã nguồn Google Apps Script đồng bộ dữ liệu về Google Sheets
                                 và tự động dùng Gmail của bạn gửi link kích hoạt cho khách.
- Các file ảnh chất lượng cao phục vụ giao diện:

2. HƯỚNG DẪN KHỞI CHẠY TRÊN MÁY TÍNH:
--------------------------------------------------------------------------------
Cách 1: Nhấp đúp chuột vào file `START_SERVER.bat`
Cách 2: Mở PowerShell tại thư mục này và gõ:
        powershell -ExecutionPolicy Bypass -File server.ps1

Đường dẫn truy cập:
- Trang Bán Hàng: http://localhost:8080/
- Trang Quản Trị: http://localhost:8080/admin

--------------------------------------------------------------------------------
3. HƯỚNG DẪN ĐƯA LÊN HOSTING / TÊN MIỀN ONLINE (NẾU MUỐN):
--------------------------------------------------------------------------------
- Vì toàn bộ hệ thống viết bằng HTML5/CSS3/JavaScript hiện đại (Tailwind CSS CDN, Lucide, VietQR),
  bạn có thể đưa trực tiếp lên:
  + Hosting cPanel / DirectAdmin: Tải toàn bộ file trong thư mục này lên thư mục `public_html`.
  + Nền tảng miễn phí (Netlify, Vercel, GitHub Pages, Cloudflare Pages): Kéo thả toàn bộ thư mục.
  + Khi chạy online, khách hàng vào `tenmien.com` sẽ thấy trang bán hàng, và bạn vào
    `tenmien.com/admin.html` để quản trị đơn hàng!
