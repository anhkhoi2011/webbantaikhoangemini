Trung Tâm Điều Khiển Bot Telegram Tự Động

✓ Tự Động Hoạt Động

Báo khách mua tức thì • Cảnh báo tồn kho gần hết • Báo cáo tổng kết ngày lúc 10h

Tự động gửi:
Lấy từ @BotFather trên Telegram (miễn phí 100%).
Chat với @userinfobot để lấy ID cá nhân của bạn.
⚠️ Khi số mã license 'Sẵn sàng' chạm mức này, bot sẽ gửi tin cảnh báo khẩn cấp.
📊 Báo cáo tổng kết: Lượt truy cập, đơn hàng, doanh thu, tỷ lệ CR, nguồn bấm vào.
💡 Cấu hình được lưu tự động vào bộ nhớ và đồng bộ ngay với trang bán hàng cho khách.
⚡ Khu Vực Bắn Thử Tin Nhắn Trực Tiếp Về Telegram: Bấm nút để test định dạng tin nhắn ngay
📖 HƯỚNG DẪN 3 BƯỚC KẾT NỐI BOT TELEGRAM CỦA BẠN (CHỈ MẤT 1 PHÚT):
Bước 1: Lấy Bot Token Mở Telegram tìm kiếm @BotFather ➔ bấm Start ➔ gõ /newbot ➔ đặt tên bot ➔ BotFather sẽ gửi cho bạn đoạn mã HTTP API Token (VD: 7123984012:AAH9...).
Bước 2: Lấy Chat ID của bạn Mở Telegram tìm kiếm @userinfobot ➔ bấm Start ➔ bot sẽ gửi lại Id của bạn (VD: 981240192). (Nếu muốn báo về nhóm, mời bot vào nhóm rồi lấy group ID).
Bước 3: Dán & Bấm Lưu Dán Token vào ô (1), dán Chat ID vào ô (2) bên trên rồi bấm LƯU CẤU HÌNH. Sau đó bấm các nút Bắn Thử để thấy tin nhắn nhảy về điện thoại ngay lập tức!
